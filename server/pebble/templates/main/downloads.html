Installing on Android

  1. On the management page (on your own device), add the phone or tablet (platform Android) and note its 6-digit pairing code.
  2. On the device, open {{ server_url }}/downloads in Chrome and download pebble-agent.apk. Allow Chrome to install unknown apps when asked. On a Family Link device, a parent may need to allow this first.
  3. Open Pebble, enter the server {{ server_url }} and the pairing code.
  4. Follow the checklist in the app: allow Usage access and running in the background (and autostart on Xiaomi, Oppo, Vivo or Huawei).
  5. Optional: add the Pebble widget to the home screen.

Installing on Windows

  1. On the management page (on your own device), add the PC and note its 6-digit pairing code. The code works once and for 15 minutes.
  2. Download pebble-agent.exe on the PC.
  3. Open PowerShell as administrator in the download folder and run:
    .\pebble-agent.exe install --server {{ server_url }} --code 123456
  4. Make sure the kids use standard (not administrator) Windows accounts.
